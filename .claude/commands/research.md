# /research

## Delegate

Delegate to the **research** skill. Activate when a question needs evidence
from outside the session, such as a dependency's real behaviour, a
specification, or an upstream API contract: the skill runs the reading in a
background agent against primary sources, cites every claim back to the
source that owns it, and writes the result as a Markdown brief in the
repository, next to where the repo already keeps such notes.
