# /tdd

## Delegate

Delegate to the **tdd** skill. Activate when a change to `<app>` is driven
test-first, whether a new feature, a bug fix, or a request for integration
tests: the skill agrees the seams under test up front, then runs one vertical
slice at a time (failing test, minimum implementation, next slice), keeps
the tests behavioural and non-tautological, and leaves the suite green.
