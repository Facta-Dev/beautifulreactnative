# /grilling

## Delegate

Delegate to the **grilling** skill. Activate when a plan, decision or idea
for `<app>` needs to be stress-tested before implementation: the skill maps
the decisions as a design tree, asks the whole settled frontier in numbered
rounds with a recommended answer per question, looks up the facts itself
rather than asking, and stops only when every branch is settled, deferred or
explicitly open.
