# /clean-room-rebuild

## Delegate

Delegate to the **clean-room-rebuild** skill.

Activate when an `<app>` feature must reproduce how a target behaves but the
source is not licensed for reuse. The skill reads only what a user or visitor
sees, copies no logos, photos, brand names or long text, keeps a credits table
of everything reused, and states plainly that the work is based on the
original.

Do not activate when the rights to read the source exist (use the per-stack
port skill) or when nothing protected is being reproduced.
