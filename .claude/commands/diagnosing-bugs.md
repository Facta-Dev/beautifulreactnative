# /diagnosing-bugs

## Delegate

Delegate to the **diagnosing-bugs** skill. Activate when the request is to
diagnose a broken, flaky, failing or slow behaviour in `<app>`: build the
tight red-capable feedback loop first, minimise the repro, rank falsifiable
hypotheses, instrument one variable at a time, then fix and land the
regression test. Not for a known cause with only the fix left to write, and
not for reviewing a diff.
